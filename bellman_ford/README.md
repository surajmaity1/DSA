# Bellman Ford Algorithm

### Docs

- [Wikipedia](https://en.wikipedia.org/wiki/Bellman%E2%80%93Ford_algorithm)

### Note

- Helps to detect negative cycle in a directed graph.
- Bellman ford will work on only directed graph. To make it work with undirected graph, we need to convert it to directed graph.
- During implementation, edges can be given any order
